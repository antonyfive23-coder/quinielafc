📋 PASO 1 — Crear proyecto Firebase (gratis)
1. Abre firebase.google.com
2. Pulsa "Ir a la consola" → "Crear proyecto"
3. Ponle un nombre (ej: miQuiniela)
4. Desactiva Google Analytics → "Crear proyecto"
5. Entra al proyecto → menú lateral → Firestore Database
6. Pulsa "Crear base de datos" → modo Producción → elige región → Listo
🚀 Abrir Firebase Console
🔑 PASO 2 — Copiar credenciales
1. En Firebase Console, haz clic en el ⚙️ engranaje → "Configuración del proyecto"
2. Baja hasta "Tus apps" → pulsa el icono </> Web
3. Ponle un nombre → "Registrar app"
4. Verás un bloque de código con apiKey, projectId y appId
5. Copia esos 3 valores y pégalos abajo
⚡ PASO 3 — Pegar y conectar
