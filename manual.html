🔥 PASO 1 — Crear tu base de datos Firebase
⏱️ Tiempo estimado: 5 minutos. Firebase es completamente gratuito para hasta 400 usuarios diarios. No necesitas tarjeta de crédito.
1

Abre Firebase Console

En tu navegador, ve a:

firebase.google.com

Inicia sesión con tu cuenta de Google. Si no tienes, créala gratis.

2

Crear nuevo proyecto

Pulsa "Ir a la consola" → "Crear un proyecto".
Ponle un nombre (ej: miQuiniela2026).
Desactiva Google Analytics → pulsa "Crear proyecto".
Espera ~30 segundos → pulsa "Continuar".

3

Crear la base de datos Firestore

En el menú lateral izquierdo, busca y pulsa "Firestore Database".
Pulsa "Crear base de datos".
Selecciona "Comenzar en modo de producción" → Siguiente.
Elige la región más cercana (ej: europe-west1) → "Listo".

4

Configurar reglas de seguridad

En Firestore, pulsa la pestaña "Reglas". Borra el contenido y pega esto exactamente:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Pulsa "Publicar".

5

Añadir dominio autorizado NUEVO

Ve a Authentication → Configuración → Dominios autorizados.
Pulsa "Agregar un dominio" y añade la URL donde tienes la app alojada.
Ejemplo: tuusuario.github.io

6

Registrar tu app web

Pulsa el ⚙️ engranaje (junto a "Descripción general del proyecto") → "Configuración del proyecto".
Baja hasta "Tus apps".
Pulsa el icono </> (Web).
Ponle un nombre (ej: QuinielaWeb) → "Registrar app".

7

Copiar las credenciales

Verás un bloque de código como este:

const firebaseConfig = {
  apiKey: "AIzaSy...",
  projectId: "tu-proyecto-12345",
  appId: "1:123456:web:abc123",
  ...

Necesitas copiar 3 valores: apiKey, projectId y appId. Anótalos.

✅ Ya tienes Firebase listo. Ahora vamos a conectarlo con la app.
🌐 PASO 2 — Alojar la app en GitHub Pages (gratis)
💡 GitHub Pages es gratuito y permite que todos accedan a la app desde cualquier móvil con una URL fija.
1

Crear cuenta en GitHub

Ve a github.com y crea una cuenta gratuita si no tienes.

2

Crear repositorio

Pulsa "New repository". Ponle un nombre (ej: quinielafc). Márcalo como público. Pulsa "Create repository".

3

Subir los archivos

Sube los 3 archivos que recibirás: index.html, manifest.json y sw.js.
Pulsa "Add file → Upload files", selecciona los 3 y pulsa "Commit changes".

4

Activar GitHub Pages

Ve a Settings → Pages. En "Source" selecciona "Deploy from a branch" → rama main → carpeta / (root). Pulsa "Save".

En 1-2 minutos tu URL estará activa:

https://tuusuario.github.io/quinielafc/
✅ Comparte esa URL con todos los jugadores. Desde cualquier móvil con Chrome pueden acceder y unirse al grupo.
⚡ PASO 3 — Conectar la app a Firebase
🔑 Solo el administrador necesita hacer esto una vez. Las credenciales se guardan automáticamente para futuras sesiones.
1

Abrir la app

Abre la URL de GitHub Pages en Chrome. Introduce la contraseña de acceso (por defecto: Mundial2026).

2

Ir a la sección Firebase

Pulsa el botón ⚽ APOSTAR en la barra inferior.
Baja hasta el panel "🔥 Firebase" con 3 campos: API KEY, PROJECT ID y APP ID.

3

Pegar las credenciales

Pega los 3 valores que copiaste de Firebase:
• API KEY → valor de apiKey
• PROJECT ID → valor de projectId
• APP ID → valor de appId

4

Conectar y verificar

Pulsa el botón naranja "🔥 CONECTAR".
Si ves "Firebase conectado - sync en tiempo real activo" en verde, ¡todo está listo!

Desde este momento la app recuerda las credenciales. En futuras sesiones Firebase se conecta solo al arrancar.

👥 PASO 4 — Crear tu grupo de amigos
1

Crear el grupo

En la sección Apuestas, baja hasta "CREAR GRUPO".
Escribe el nombre del grupo, tu apodo y elige un emoji.
Pulsa "🚀 CREAR GRUPO".

2

Compartir el código

Verás un código de 6 letras (ej: ABC123).
Compártelo con tus amigos por WhatsApp, Telegram o como prefieras junto con la URL de la app.

3

Los demás se unen

Cada jugador debe:
1. Abrir la URL en Chrome
2. Introducir la contraseña (Mundial2026)
3. Ir a Apuestas → Unirme a un grupo
4. Introducir el código de 6 letras
5. Escribir su apodo y elegir un emoji
6. Pulsar "🔑 UNIRME AL GRUPO"

🔥 Sincronización automática: Un indicador verde en la esquina inferior derecha confirma que el polling está activo. Los datos se sincronizan cada 5 segundos entre todos los móviles.
🎯 PASO 5 — Cómo apostar
1

Seleccionar un partido

En la pestaña Partidos, pulsa sobre cualquier partido disponible para abrirlo.

2

Elegir resultado y marcador

Selecciona 1 (local gana), X (empate) o 2 (visitante gana).
Introduce el marcador exacto (opcional pero suma más puntos).
Añade las monedas que quieres apostar en el campo 🪙.

3

Confirmar la apuesta

Pulsa "✅ Confirmar apuesta". Las monedas apostadas se descuentan inmediatamente de tu saldo y la apuesta se guarda en Firebase para que todos la vean.

⏰ Límite de tiempo: Solo puedes apostar antes del inicio del partido. Una vez comenzado, la apuesta se cierra automáticamente.
🪙 Sistema de Monedas ACTUALIZADO

Cada jugador empieza con 5.000 monedas. Al apostar un partido, puedes añadir monedas a tu apuesta. Las monedas apostadas se descuentan inmediatamente del saldo. Al final del Mundial, el jugador con más monedas gana el bote.

ResultadoPremioEjemplo (apuesta 100🪙)
🎯 Marcador exacto +200% de la apuesta Ganas 200🪙 → Total: +200🪙
✅ Resultado correcto +50% de la apuesta Ganas 50🪙 → Total: +50🪙
❌ Resultado incorrecto -100% de la apuesta Pierdes 100🪙
💡 Estrategia: Apuesta más monedas cuando tengas mucha confianza en el resultado. Guarda monedas para los partidos de semifinales y final.
✅ El Ranking de monedas muestra el saldo actual de cada jugador y cuánto ha ganado o perdido respecto al inicio (en verde/rojo).

El administrador del grupo confirma los resultados desde el panel "Admin — Confirmar resultado" en la parte inferior de la pantalla de partidos.

💬 Chat del grupo NUEVO

Cada grupo tiene un chat en tiempo real. Accede desde Mi Grupo → pestaña 💬 Chat.

📱 Los mensajes se sincronizan automáticamente. Cuando alguien escribe un mensaje, aparece en el chat de todos los miembros del grupo en pocos segundos.
⚠️ El chat requiere que Firebase esté conectado. Si ves el chat vacío, espera unos segundos a que se sincronice o sal y vuelve a entrar a la pestaña Chat.

❓ Preguntas frecuentes

¿Cuántos usuarios pueden usar la app al mismo tiempo?

Con Firebase gratuito, hasta 400 usuarios activos diarios sin coste. Más que suficiente para grupos de amigos.

¿Se pierden los datos si cierro la app o recargo la página?

No. Los datos están en Firebase. Al volver a abrir la app, Firebase se conecta automáticamente y restaura tu grupo y apuestas.

¿Por qué aparece un indicador verde en la esquina inferior derecha?

Es el indicador de sincronización activa. Muestra la hora de la última sincronización con Firebase. Si desaparece, recarga la página.

¿Qué pasa si los resultados de ESPN no son correctos?

El administrador del grupo puede introducir los resultados manualmente. La sincronización con ESPN es automática pero el admin siempre tiene el control final.

¿Puedo usar la misma base de datos Firebase para varios grupos?

Sí. Un solo proyecto Firebase puede alojar múltiples grupos sin problema.

¿Cómo vuelvo a entrar si borro la caché del navegador?

Abre la URL → introduce la contraseña → ve a Apuestas → Unirme a un grupo → introduce el código y tu mismo apodo. El sistema recupera tu historial de apuestas automáticamente.

🔑 Cómo volver a entrar al grupo
1

Pide el código al organizador

El código de 6 caracteres del grupo sigue existiendo en Firebase aunque hayas cerrado la app o borrado la caché.

2

Introduce el código y tu apodo

Ve a Apuestas → Unirme a un grupo. Escribe el código y exactamente el mismo apodo que usabas antes.

3

Tus apuestas anteriores siguen ahí

🔔 Notificaciones push NUEVO v4

La app envía notificaciones automáticas cuando hay actividad en tu grupo.

1

Activar notificaciones

Al entrar al grupo por primera vez, el navegador preguntará si quieres recibir notificaciones. Pulsa "Permitir".

2

Qué notificaciones recibirás

• ⚽ Nueva apuesta — cuando un compañero apuesta un partido con su resultado
• 🎯 Resultado acertado — cuando alguien del grupo acierta un resultado
• 👥 Nuevo miembro — cuando alguien se une al grupo

📱 Importante: Las notificaciones solo funcionan cuando la app está abierta en Chrome. Para recibirlas en segundo plano, añade la app a la pantalla de inicio (instalar como PWA).
⚠️ No recibirás notificaciones de tus propias acciones, solo de las acciones de los demás jugadores del grupo.
